# 参考资料与依据说明

> 本文档说明本项目设计与验证所依据的资料来源：参考文献、关键规则的依据映射、本队技术文献库的组织体系。目的在于使设计文档中的每项规则与参数可溯源、可查证。

## 1. 参考文献

| # | 文献 | 在本项目中的用途 |
|---|---|---|
| 1 | ARINC Specification 664, Part 7: Avionics Full-Duplex Switched Ethernet Network. Aeronautical Radio, Incorporated. | 协议规则总依据：帧格式、VL、BAG、SN/IC/RM、SkewMax、分片（见 doc/01、doc/02 第二篇各专题「规范依据」） |
| 2 | IEEE Std 802.3: Ethernet. IEEE. | 以太网帧、FCS、GMII 接口基础 |
| 3 | RFC 791: Internet Protocol. IETF, 1981. | IPv4 头、分片与重组机制（MF、片偏移、标识） |
| 4 | RFC 768: User Datagram Protocol. IETF, 1980. | UDP 头与校验和口径 |
| 5 | Boyer M. Tutorial on AFDX. ONERA / Université Paul Sabatier, 2018. | 入门与概念校核：VL/BAG/抖动的教学性阐释 |
| 6 | Xilinx Application Note XAPP1130: ARINC 664 Part 7 / AFDX Reference Design. Xilinx, Inc. | 厂商参考设计的架构对照（端系统分层、VL 表组织） |
| 7 | 上海交通大学学位论文：AFDX 端系统虚拟链路层相关研究，2011. | VL 层实现路线的学术对照 |
| 8 | 《电讯技术》：AFDX 网络架构与协议分析综述，2010. | 架构与关键协议（SkewMax 等）的中文综述依据 |
| 9 | 全国大学生嵌入式芯片与系统设计竞赛 2026 FPGA 赛道选题指南（中科亿海微命题）及官方答疑（汇总见 doc/05） | 赛题指标、交付形态与解释口径的最终依据；与标准原文不一致处以官方答疑为准 |

## 3. 本队技术文献库（资料组织体系）

项目启动阶段即建立 AFDX 技术文献库，按「规范 → 实现 → 验证 → 本工程文档」分类编号管理，作为设计与查证的共同底座：

```
00 协议定义与规范说明（含标准原文合法获取途径说明）
01 协议规范与教程（标准原文、Boyer 教程、AFDX 与 TSN 对比等）
02 工程实现论文（嵌入式实现、硬件实现、硬连线 NIC 等）
03 开源工程代码（AFDX 仿真工程等）
04 分析与验证
05 厂商 IP 与数据手册
06 设计文档（架构、构建与测试计划、各子系统分册、时序分析）
07 RTL 代码模板
08 仿真验证
09 上位机工具
10 协议机制专题（SN/SkewMax/BAG/令牌桶专题、双冗余与端系统规范依据摘录及实现对照）
补充资料（专题补充与待补清单）
```

## 4. 原件未随包提交说明

文献库原件**未随本提交包提交**，原因有二：其一，标准原文（文献 1）为授权购买文档，不宜再分发；其二，文献库总体积约 59 MB，以论文与代码原件为主，与交付物（设计、代码、测试证据）无直接对应关系。本包内的可溯源性由本文档与 doc/01（规格笔记，逐项标注出处）、doc/02 第二篇（各专题「规范依据」）、doc/05（官方答疑汇编）共同承担；文献库目录结构如 §3 所列，原件随队存档备查。
