# GEM-001 测试用例矩阵与测试报告骨架（GEM-001-test-matrix.md）

> **编制说明**：本矩阵基于 T5 文件契约（输入激励 `msg_tx.hex` + `msg_lens.txt` + `case.json`；金标准 `golden_{A,B}.hex` + `frame_{A,B}.lens`；Python 参考模型 `afdx_ref.py`），面向 eLinx 纯仿真与 Verilog-2001 语境编制。共规划 **53 条**高强度、量化测试用例（覆盖帧长边界、多 VL 调度、SN/IC/RM、IP 分片、错误注入、单网故障、指标实测 7 大维度），后附规范化测试报告骨架。

---

## 第一部分：测试契约与量化准则

1. **接口契约**：
   - 激励注入：应用口 `tx_data[7:0]` + `tx_valid`（`tx_valid` 上升沿到下降沿为一条完整消息，前 2 字节为大端 VLID，后续为原始应用载荷）。
   - 接收输出：应用口 `rx_data[7:0]` + `rx_valid`（`rx_valid` 高电平时前 2 字节为大端 VLID，后续为解封装重组交付的原始应用载荷）。
   - 网络接口：内部 GMII 链路双网（A/B 双网各一组 8bit @ 125 MHz 单时钟域，千兆线速）。
2. **术语口径**：
   - **端到端时延**：任意 VL 的首个 `tx_data` 字节有效输入时刻至 `rx_data` 接收到该首字节时刻的总时长（$\Delta t = t_{rx\_first} - t_{tx\_first}$）。
   - **有效载荷吞吐率**：单位时间内在 `tx_data` 上稳定注入并经系统成功接收交付的应用载荷纯字节速率（A/B 双网冗余副本只计一次，不含 VLID 2B、不含 IP/UDP 报头、不含填充 Padding、不含前导码与 IFG）。
   - **抖动**：同一 VL 在相同帧长下的端到端时延最大值减去最小值（$Jitter = Latency_{max} - Latency_{min}$）。
