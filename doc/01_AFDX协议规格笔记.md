## 1. 帧格式（字节级；偏移从目的 MAC 第 1 字节 = 0 起算）

```
 Preamble | SFD | 目的MAC | 源MAC | 类型  | IPv4 头 | UDP 头 | AFDX载荷 | Padding | SN | FCS | IFG
   7B     | 1B  |   6B    |  6B   |  2B   |  20B    |  8B    | 1~1471B  |  0~16B  | 1B | 4B  | 12B
```
【原文】P7-24 Figure 3-19：最小帧 64B（载荷 1~17B + Padding 0~16B），最大帧 1518B（载荷 1471B）。

**帧长算式自查**：
- 最大帧 L_max = **14（MAC 头）+ 1500（数据区 = IP 包 1499 + SN 1）+ 4（FCS）= 1518**；
  最小帧 L_min = 14 + 46 + 4 = 64。
- **帧长不含 Preamble/SFD/IFG**；线上占用另计（前导 8 + IFG 12 = +20B）。
- 等价式 L = N + Padding + 47，Padding = max(0, 17−N)：N=1 → 64，N=1471 → 1518。
- 实现侧已由 afdx_ref 自测证明（1471B 载荷 → 1518B、1B 载荷 → 64B），文档无残留错误。

## 2. 序列号 SN 与完整性检查 IC

### 2.1 发送端 SN（【原文】P7-23 §3.2.6.1）

- SN 一个八位组，**范围 0~255**；每个 VL 独立。
- **初始值 = 0**；发送 ES 复位后重新赋 0（SN=0 只在复位后出现一次）。
- 之后每帧 +1；**255 后回绕到 1**（0 不再出现）。
- A/B 两份副本使用同一 SN（一次调度递增一次）。
- 冗余副本应在 **0.5ms** 内先后发出【原文 P7-24】。

### 2.2 接收端 IC（【原文】P7-24~25 §3.2.6.2.1）

- 独立于 RM，按 VL、按网分别执行；IC 可按 VL 配置关闭（关闭则双网帧全收）。
- **IC 状态维度**：PSN/seen 等状态按 **（VL × 网络 A/B）独立维护**——
  两网各自判窗、各自计数，A 网副本不得被 B 网的 IC 状态误杀；**单网复位/故障仅重置该网状态**，
  另一网连续运行不受影响。
- 合法窗口：**[PSN+1, PSN+2]**（"+" 考虑回绕：PSN=254 → {255, 1}）。
- **PSN = 上一帧"收到"（不必然转发）的 SN** → 不论帧被接受还是丢弃，PSN 一律更新为当前帧 SN（重新同步语义）。
- 特殊接受：**RSN=0**（发送端复位标志）；**接收 ES 复位后的第一帧**。
- 不满足者丢弃并计数。
- 与 v2 §5.3 对照：一致（v2 的 psn 总是更新、nxt(x)=x≥255?1:x+1、IC_WINDOW=2、ic_en 均有原文依据）。
- 注意：00_等效规范 §6.2 写"接受后更新 psn"不完整——以原文"previous frame received (but not necessarily forwarded)"为准【已澄清】。

### 2.3 冗余管理 RM（【原文】P7-25 §3.2.6.2.2）

- **First Win**：RM 激活时交付**先收到的**冗余帧；"硬件复位时间假定大于 SkewMax"。
- **RM 只用 RSN 作为接受/拒绝判据**（IC 是独立任务）。
- **转发必须按 RSN 递增序**（复位与偶发丢帧后仍成立）；**若自上一帧后已超过 SkewMax，则下一帧无论 SN 为何都接受**。
- "只转发序内帧、不要求重排序" → 单网丢一帧可能连带丢其 B 网副本（原文图 3-20 例）。
- SkewMax 按 VL 配置（ms），由系统集成者按拓扑给出，标准不定值（原文示例量级：BAG=1ms、SkewMax=5ms → 最大 SN 偏移 ≪128）。
- 每 VL 可配：冗余（A/B 双发）/ 非冗余（仅 A 或仅 B）；接收端可配 RM 激活（交付其一）或关闭（双份都交付）。
- 与 v2 §5.4 对照：**采用 v2 的 MODE=1（d() 环形距离窗）为默认且唯一实现模式**——`d(sn,rsn)=((sn-1)-(rsn-1)+255) mod 255`，d=0 重复帧丢弃、1~RM_WIN(127) 新帧接受、128~254 旧帧丢弃、超 SkewMax 无条件接受。**v2 的 MODE=0（任意 sn≠rsn 即收）不满足"递增序"要求，弃用**。状态 rsn(8b) + valid + t_last(24b µs)。
- **SN=0 与复位初态的旁路规则**：
  - IC 侧：RSN=0（发送端复位标志）或"接收 ES 复位后第一帧" → 特殊接受（原文 P7-25）；
  - RM 侧：`valid=0`（接收复位初态）或 `sn=0` 时**旁路 d() 距离窗，直接接受**，并同步
    rsn=sn、t_last=now、valid=1——避免 d(0,rsn) 落入"旧帧"区间被误杀；
  - RTL 实现约束：距离计算用 **9 位无符号减法 + 条件修正**实现，**禁止有符号取模**（综合与
    仿真语义一致性问题）。

## 3. BAG 与流量管理

- BAG ∈ {1,2,4,8,16,32,64,128} ms，每 VL 配置【标准 §3.2.3；00_等效规范 §4】。
- 同一 VL 相邻帧起始间隔 ≥ BAG；调度抖动约束见标准 §3.2.4（MAX_Latency ≤ BAG + Max_jitter + Tech_Latency；分片消息 p 帧场景 ≤ p×BAG + jitter + tech——与 doc/05"跨多 BAG 分片消息不受单帧 1~2ms 约束"一致）。
- Jitter 上界参考式（P7 §3.2.4 原文待细核【W1 遗留核对项】）：J_max ≤ 40µs + Σ(S_max,j+20)×8/R ≤ 500µs。
